# DSH 手机遥控台 · 工业版（面向小白）

> 目标：**双击安装 → 填几个账号 → 手机就能远程指挥电脑、写日记发网站**。
> 不需要懂代码、不需要改配置文件。

---

## 📦 这个文件夹里有什么

| 文件/文件夹 | 作用 |
|---|---|
| `一键安装.ps1` | ⭐ 安装向导（电脑端自动装 Tailscale、配 DSH、部署手机页面、配网站发布） |
| `手机遥控台/` | 手机页面（PWA），由安装向导自动部署 |
| `日记发布工具/` | 生成/发布日记的脚本（config.json.example 是配置示例） |
| `配置模板/` | DSH 信任配置参考（向导会自动生成） |
| `手机端操作.md` | 手机上要做的三件事 |

## 🚀 安装步骤（电脑端，总共 3 步）

### 第 1 步：装 DSH 桌面客户端（开源社区版）
电脑上安装 **DeepSeek Harness 桌面客户端**（开源引擎，社区打包的"下载即用"版，GitHub 上可搜到，如 `dsh-desktop`），打开一次，确认能正常聊天。（这是"大脑"）
> ⚠️ 注意：官方 DeepSeek 网站**没有**这个桌面客户端，它是开源社区构建，下载时认准靠谱仓库即可。

### 第 2 步：运行安装向导
1. 找到本文件夹里的 **`一键安装.ps1`**
2. **右键 → 使用 PowerShell 运行**
3. 跟着提示走，需要输入/确认的只有：
   - **Tailscale 登录**（浏览器里用你的 Google/微软/邮箱账号登录一次）
   - **GitHub 用户名、仓库名、令牌**（如果要用"写日记发布网站"；没有网站可跳过）
4. 中间弹出的"用户账户控制"窗口都点【是】
5. 完成时按提示**重启 DeepSeek 应用**

### 第 3 步：手机装 App
按 **`手机端操作.md`** 做：装 Tailscale → 登录同一账号 → 打开安装向导最后给你的网址 → 添加到主屏幕。

## 🔧 常见问题

- **HTTPS 提示没开成功** → 浏览器打开 `https://login.tailscale.com/admin/dns`，打开"HTTPS Certificates"开关，重跑向导。
- **手机打不开页面** → 确认手机 Tailscale 已连接（出现 VPN 图标），且和电脑同一账号。
- **要重新安装** → 向导会自动备份旧配置，可放心重跑。

## 📝 说明

- 安装向导会**自动备份**它改动的 DSH 配置文件（带时间戳的 .bak）。
- 每个用户用自己的 Tailscale 账号（别人进不来你的网络）、自己的 DeepSeek 账号、自己的 GitHub 令牌——互不干扰，各自付费。
- 令牌保存在你电脑的 `.dsh\.github-token`，随时可在 GitHub 设置里撤销。
